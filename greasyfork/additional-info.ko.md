YouTube 영상 페이지에서 **질문하기(Ask)** 패널을 열고 **동영상을 요약해 줘** 칩을 대신 눌러 줍니다. 영상을 열면 바로 요약이 시작됩니다.

## 하는 일

- 영상에 질문하기(Ask) 버튼이 있으면 Ask 패널을 열고 요약을 요청합니다.
- Ask가 없는 영상에서는 아무것도 하지 않습니다.
- 페이지를 새로 불러오지 않고 다른 영상으로 넘어갈 때, 창이 좁아서 Ask 버튼이 접혀 있을 때, 백그라운드 탭으로 열었을 때도 동작합니다. 백그라운드 탭은 그 탭으로 넘어간 뒤에 시작합니다.

## 필요한 것

- YouTube에 로그인되어 있고, 계정에서 Ask 기능을 쓸 수 있어야 합니다. 모든 영상에 Ask가 있는 것은 아닙니다.
- 데스크톱 사이트(`www.youtube.com`)에서만 동작합니다. 모바일 사이트 `m.youtube.com`은 지원하지 않습니다.

## 언어

버튼 문구가 아니라 YouTube 페이지 데이터로 Ask 버튼과 요약 칩을 찾기 때문에, UI 언어와 상관없이 동작합니다.

- 영어, 한국어 UI에서 처음부터 끝까지 동작을 확인했습니다.
- 일본어, 중국어(간체·번체), 스페인어(스페인·중남미), 프랑스어, 독일어, 포르투갈어(브라질), 러시아어 UI에서는 요약 칩을 찾는 것을 확인했습니다.

## 알아 두기

- 요약은 실제 Ask 요청이라서, 연 영상마다 한 번씩 Ask 기록에 남습니다.
- 스크립트가 직접 보내는 요청은 없고, 어떤 데이터도 모으지 않습니다. YouTube의 버튼을 대신 누를 뿐입니다.

## 호환성

- Firefox + Violentmonkey
- Chrome + ScriptCat

## 문제 해결

1. 브라우저 콘솔(F12)을 열고 로그 수준에서 Verbose/디버그를 켭니다.
2. 필터에 `yt-auto-summarize-multilang`을 입력합니다.
3. 정상이면 `checking video` → `opening Ask panel` → `requesting summary` 순서로 찍힙니다.

- `no Ask button`: 이 영상이나 계정에 Ask가 없습니다.
- `no Summarize chip`: 패널은 열렸지만 칩을 못 찾았습니다. UI 언어와 칩 문구를 피드백으로 알려 주세요.
