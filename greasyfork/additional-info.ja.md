YouTube の動画ページで **Ask** パネルを開き、**動画を要約して** チップを代わりにクリックします。動画を開くとすぐに要約が始まります。

## 機能

- 動画に Ask ボタンがあれば、Ask パネルを開いて要約をリクエストします。
- Ask がない動画では何もしません。
- ページを再読み込みせずに別の動画へ移動したとき、ウィンドウが狭くて Ask ボタンが折りたたまれているとき、バックグラウンドタブで開いたときにも動作します（バックグラウンドタブでは、そのタブに切り替えてから始まります）。

## 必要なもの

- YouTube にログインしていて、アカウントで Ask 機能が使えること。すべての動画に Ask があるわけではありません。
- デスクトップ版サイト（`www.youtube.com`）。モバイル版の `m.youtube.com` には対応していません。

## 言語

ボタンの文言ではなく YouTube のページデータから Ask ボタンと要約チップを見つけるため、UI の言語に関係なく動作します。

- 英語と韓国語の UI で、最初から最後まで動作を確認しました。
- 日本語、中国語（簡体字・繁体字）、スペイン語（スペイン・中南米）、フランス語、ドイツ語、ポルトガル語（ブラジル）、ロシア語の UI では、要約チップを見つけられることを確認しました。

## 注意

- 要約は実際の Ask リクエストなので、開いた動画ごとに 1 回ずつ Ask の履歴に残ります。
- スクリプト自身はリクエストを送らず、データも収集しません。YouTube のボタンを代わりにクリックするだけです。

## 対応環境

- Firefox + Violentmonkey
- Chrome + ScriptCat

## トラブルシューティング

1. ブラウザのコンソール（F12）を開き、ログレベルで Verbose（詳細）を有効にします。
2. フィルターに `yt-auto-summarize-multilang` と入力します。
3. 正常に動作していれば `checking video` → `opening Ask panel` → `requesting summary` の順に表示されます。

- `no Ask button`: この動画またはアカウントには Ask がありません。
- `no Summarize chip`: パネルは開きましたが、チップが見つかりませんでした。UI の言語とチップの文言をフィードバックで教えてください。
