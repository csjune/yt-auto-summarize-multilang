在 YouTube 影片頁面開啟 **Ask** 面板，並替你點選 **生成影片摘要** 選項。開啟影片後就會立即開始產生摘要。

## 功能

- 如果影片有 Ask 按鈕，指令碼會開啟 Ask 面板並要求摘要。
- 沒有 Ask 的影片不會做任何事。
- 在不重新整理頁面切換到其他影片、視窗較窄導致 Ask 按鈕被收合，以及在背景分頁開啟時也能運作（背景分頁會在你切換過去之後才開始）。

## 使用條件

- 已登入 YouTube，而且你的帳戶可以使用 Ask 功能。並非所有影片都提供 Ask。
- 僅支援桌面版網站（`www.youtube.com`），不支援行動版 `m.youtube.com`。

## 語言

指令碼透過 YouTube 的頁面資料而非按鈕文字來尋找 Ask 按鈕和摘要選項，因此不受介面語言影響。

- 已在英文和韓文介面中完整測試。
- 已在日文、中文（簡體、繁體）、西班牙文（西班牙、拉丁美洲）、法文、德文、葡萄牙文（巴西）和俄文介面中確認能找到摘要選項。

## 注意事項

- 每次摘要都是真實的 Ask 要求，所以每開啟一部影片，都會在 Ask 記錄中留下一筆。
- 指令碼本身不會傳送任何要求，也不會收集任何資料，只是代替你點選 YouTube 自己的按鈕。

## 相容性

- Firefox + Violentmonkey
- Chrome + ScriptCat

## 疑難排解

1. 開啟瀏覽器主控台（F12），在記錄層級中啟用 Verbose（詳細）。
2. 在篩選欄位輸入 `yt-auto-summarize-multilang`。
3. 正常運作時會依序顯示 `checking video` → `opening Ask panel` → `requesting summary`。

- `no Ask button`：這部影片或你的帳戶沒有 Ask。
- `no Summarize chip`：面板已開啟，但找不到摘要選項。請在意見回饋中告訴我們你的介面語言和該選項的文字。
